# Network CRM / Network OS

Комплект бизнес-требований для проектирования и разработки мультитенантной CRM/SaaS-платформы для сетевого маркетинга.

## Назначение комплекта

Документы являются исходной спецификацией для продуктовой декомпозиции, архитектурного проектирования, подготовки API и схемы данных, создания задач разработки и приемочного тестирования. При конфликте документов приоритет имеет `business-requirements.md`, затем `business-rules.md`, затем профильный документ. Открытые решения нельзя считать утвержденной логикой: они перечислены в `open-questions.md`.

## Правила идентификаторов

Используются префиксы BR, FR, NFR, BRULE, US, UC, ENT, INT, API, EVT, UI, AI, SEC, REP, KPI, ACC, RISK, ASM и QST. Идентификатор неизменяем после включения требования в разработку; удаленный идентификатор не используется повторно.

## Статус

Версия 0.9 — базовый BRD для обсуждения и архитектурной проработки. Все допущения требуют подтверждения владельцем продукта до промышленного запуска.
