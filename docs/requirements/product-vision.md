# Видение продукта

## 1. Резюме

Network CRM (альтернативное позиционирование — Network OS) — мультитенантная SaaS-платформа для управления полным циклом сетевого бизнеса: от первого контакта и продажи продукции до регистрации партнера, адаптации, развития структуры и достижения ранга. Платформа объединяет CRM, заказы, постпродажное сопровождение, повторные продажи, дерево партнеров, обучение, контент, мероприятия, аналитику и встроенного AI-помощника.

Система не заменяет учетную систему сетевой компании, ERP, WMS или систему расчета вознаграждений. Для MVP CRM является системой ведения взаимодействий и операционной активности; мастер-система для официальной регистрации партнера, фактических продаж, остатков, рангов и вознаграждений определяется настройкой интеграции tenant.

## 2. Проблематика

Типовой пользователь ведет контакты в телефоне, переписки — в нескольких каналах, задачи — в памяти или блокноте, материалы — в чатах, а официальную структуру — в кабинете компании. В результате отсутствуют единая история, обязательный следующий шаг, управляемая адаптация, прогноз повторного заказа и прозрачность рисков структуры. Линейная CRM не отражает одновременные роли человека и отношения спонсорства, наставничества и клиентского обслуживания.

## 3. Цели

| ID | Цель | Проверяемый результат |
|---|---|---|
| BR-001 | Создать единый профиль человека | Один Contact поддерживает несколько ролей без дублирования истории |
| BR-002 | Управлять рекрутингом отдельно от продаж | Независимые воронки, этапы, SLA и конверсии |
| BR-003 | Обеспечить работу со структурой | Дерево, ветки, поколения, ранги и области видимости |
| BR-004 | Замкнуть цикл заказа и сопровождения | Получение заказа запускает управляемый follow-up |
| BR-005 | Повысить повторные продажи | Расчет ожидаемого окончания продукта и подтверждаемый повторный заказ |
| BR-006 | Стандартизировать адаптацию | Автоматическое назначение маршрута новичку |
| BR-007 | Дать лидеру управленческую аналитику | Показатели веток и объяснимые сигналы риска |
| BR-008 | Обеспечить безопасную AI-поддержку | AI предлагает, объясняет и журналирует; критичные действия подтверждает человек |
| BR-009 | Поддержать SaaS и White Label | Изоляция tenant и настраиваемый бренд/процессы |

## 4. Границы

В продукт входят CRM, рекрутинг, продажи, структура, продукты, заказы, сопровождение, задачи, коммуникационная история, контент, обучение, мероприятия, уведомления, аналитика, администрирование, AI и интеграционный слой.

В базовый контур не входят производство, закупки, полноценный складской учет, бухгалтерия, расчет налогов как налоговая система, расчет вознаграждений по произвольному маркетинговому плану, медицинская диагностика, неофициальный парсинг социальных сетей и автономная массовая рассылка.

## 5. Заинтересованные стороны

- владелец SaaS: экономика продукта, безопасность, эксплуатация и общеплатформенные настройки;
- сетевая компания: процессы, каталог, структура, официальные данные и White Label;
- администратор компании: конфигурация tenant и контроль качества данных;
- партнеры, лидеры и наставники: ежедневная операционная работа;
- клиенты: заказы, согласия и история обслуживания;
- контент-менеджеры и тренеры: утвержденные материалы и обучение;
- юридическая служба и DPO: правила обработки данных и коммуникаций;
- поддержка и эксплуатация: инциденты, аудит и интеграции.

## 6. Термины

| Термин | Определение |
|---|---|
| Tenant | Изолированный контур одной сетевой компании или самостоятельной организации |
| Contact | Базовый профиль физического лица в tenant |
| ContactRole | Роль Contact: клиент, кандидат, партнер и иные роли; роли могут сочетаться |
| Candidate | Проекция Contact в процессе рекрутинга |
| Client | Проекция Contact для продаж и сопровождения |
| Partner | Проекция Contact после регистрации партнером |
| User | Учетная запись с доступом к системе; Contact не обязан быть User |
| Sponsor | Партнер, определяющий официальное положение участника в структуре |
| Mentor | Пользователь, назначенный для сопровождения; может отличаться от Sponsor |
| Responsible | Пользователь, отвечающий за CRM-работу по объекту |
| NetworkNode | Положение Partner в версии сетевой структуры |
| Ветка | Поддерево от выбранного NetworkNode |
| Поколение | Расстояние в ребрах от выбранного партнера вниз по дереву |
| Личный объем | Объем, отнесенный к партнеру по правилам компании |
| Групповой объем | Объем структуры по правилам компании |
| Opportunity | Экземпляр процесса в воронке рекрутинга или продаж |
| Follow-up | Настраиваемый сценарий действий после получения продукции |
| Активный партнер | Партнер, отвечающий настраиваемому правилу активности |
| AI-рекомендация | Необязательное, объяснимое предложение системы с аудитом принятия |
| Мастер-система | Авторитетный источник конкретного типа данных |
| White Label | Брендированный вариант tenant на общей платформе |
| PII | Персональные данные, позволяющие идентифицировать человека |
