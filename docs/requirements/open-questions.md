# Открытые вопросы

Решения ниже не блокируют подготовку архитектуры, но блокируют промышленную реализацию связанных функций.

| ID | Вопрос | Временное решение | Владелец решения | Влияние |

| QST-004 | Какая система является master для заказов, цен и остатков? | Настраивать по сущности | Архитектор/компания | Integration |
| QST-005 | Допустимо ли ручное создание партнеров без внешней регистрации? | Только при внутреннем режиме структуры | Компания | Network |
| QST-006 | Разрешена ли смена sponsor и требуется ли согласование? | Версионировать, только администратор | Компания | Structure |
